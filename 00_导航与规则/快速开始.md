 # 快速开始
 
 ## 打开知识库
 按 Win+R，输入：
 ```
 F:\codex知识库
 ```
 （注：原 C:\Users\Administrator\Documents\Codex\衍谷知识库 已迁移至 F:\codex知识库\）
 
 ## 找文件
 - LLM 维护的内容目录：根目录 `index.md`（按 LLM Wiki 模式重建，见 `SCHEMA.md`）
 - 人读快速跳转：本目录 `索引总表.md`（legacy）
 - 时间线：`log.md`
 
 ## 存文件
 新文件直接存到对应区域文件夹，旧版移入 `_归档`
 
 ## 常用入口
 - 生成新方案 → 参照 03_合作伙伴/ 的协议模板
 - 调整课表 → 参照 02_产品课程/
 - 准备政府申报 → 参照 04_政府政策/
 - 做竞品对标 → 参照 05_竞争市场/
 - 需要我帮忙 → 直接对我说：参照衍谷知识库，为XX生成XX
