# 01-speeches-writings · 芒格主要公开产出

## 核心一手来源

### 《穷查理宝典》(Poor Charlie's Almanack, 2005)
- **编者**：Peter D. Kaufman
- **内容**：汇集芒格主要演讲、文章与谈话，书名致敬本杰明·富兰克林《穷理查年鉴》
- **核心篇章**：
  - 1994 USC商学院演讲「论基本的普世智慧」——多元思维模型格栅首次完整阐述
  - 1995/2005 哈佛大学演讲「人类误判心理学」——25种心理倾向系统整理
- **证据等级**：一手（芒格本人演讲原文，编辑整理）

### 《芒格之道》(2023 中信出版)
- **内容**：每日期刊(Daily Journal)股东会讲话 1987—2022 完整整理
- **价值**：晚年独立思考记录，比伯克希尔问答更自由表达
- **证据等级**：一手（股东会问答转录）

## 关键引语原始出处核验

| 流行引语 | 原始载体 | 来源说明 |
|----------|----------|----------|
| **"反过来想，总是反过来想"** | 多个演讲，源自Carl Jacobi | 借用数学家雅可比，推广为通用决策工具 |
| **"我只想知道将来我会死在哪里，这样我就永远不去那里"** | 1986哈佛演讲 | 逆向思考最著名表达 |
| **"告诉我激励，我就告诉你结果"** | 1995哈佛演讲「人类误判心理学」#1 奖惩超级反应倾向 | 激励模型核心命题 |
| **"在手拿铁锤的人看来，世界就像一颗钉子"** | 1994 USC演讲 | 嘲讽单一学科思维 |
| **"大钱不在买卖，而在等待"** | 多次股东会谈话 | 复利耐心原则 |
| **"知道你不知道什么，比聪明更有用"** | 能力圈相关论述 | 能力圈核心洞见 |

## 原创性澄清

| 概念 | 原创性 | 说明 |
|------|--------|------|
| 多元思维模型格栅 / Latticework | ✅ 芒格原创 | 1994年首次完整提出 |
| Lollapalooza效应 | ✅ 芒格原创 | 自造词描述多因素叠加非线性结果 |
| 25种人类误判心理学 | ✅ 芒格独立框架 | 借鉴Cialdini《影响力》但分类体系原创 |
| "100个思维模型清单" | ❌ 他人整理 | 芒格只说"需要约80-90个模型"，从未给出具体清单 |
| 逆向思考(Inversion) | ❌ 源自Carl Jacobi | 芒格从数学推广到商业决策通用工具 |
| 能力圈 | 与巴菲特共同发展 | 芒格版本更强调跨学科扩展能力圈 |
| 铁锤人思维 | ❌ 借用马克·吐温/马斯洛 | 芒格升级为反对单一学科核心论据 |
