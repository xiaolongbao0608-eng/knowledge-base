# 03-critiques-controversies · 批评与争议

本文件直记不调和，保留对立声音。

## 主要争议议题

### 1. 对加密货币的极端敌意
- **芒格立场**：称其"恶心、违背文明利益"，主张政府全面禁止，称反对者都是"白痴"。长期认为加密是"庄家100%胜率的赌博契约"。钦佩中国禁止加密的决策。
- **批评声音**：
  - 被指技术盲，未区分比特币与其他加密项目，一概而论
  - "希望政府禁止"立场与其一贯自由市场主张矛盾，被批双标
  - 道德化打压不同投资选择，缺乏谦逊

### 2. 科技股与代际盲区
- **芒格立场**：长期将高科技/制药归入"太难"堆，晚年接受苹果（重新定义为"消费特许经营"）
- **批评声音**：
  - "能力圈"原则既是纪律也是盲区，错过半导体等大机会
  - 暴露代际局限，老年人对新技术天然排斥

### 3. 中国立场与阿里巴巴投资
- **芒格立场**：长期公开看多中国，认为"中国龙头企业更强更好更便宜"，2021建仓阿里
- **争议**：
  - 建仓后阿里股价大幅下跌，芒格自承"最大失误之一"
  - 批评认为对中国监管环境/政策风险估计偏低
  - 支持者指出这是单一标的失误，长期中国立场逻辑自洽

### 4. 富国银行长期持有
- **事件**：长期持有后因虚假账户丑闻清仓
- **批评**：未能在文化恶化前及时退出，暴露"护城河叙事"盲区
- **芒格回应**：将此作为"错误激励摧毁文化"的反面教材，未认错但做机制分析

### 5. ProPublica巴菲特交易疑云
- **事件**：ProPublica质疑巴菲特个人交易与伯克希尔交易时间相近
- **芒格立场**：无条件维护巴菲特
- **批评**：对合伙人绝对忠诚可能削弱客观性

### 6. 高管薪酬痼疾
- **芒格立场**：承认美国企业高管激励过度问题，但"拿不出更好建议"
- **批评**：洞察深刻但缺乏解决方案，显务实局限

## 体系性批评

| 批评维度 | 内容 |
|----------|------|
| **门槛过高** | 多元思维模型对普通人太难，需要"不随大流"性格，二者皆非轻易习得（考夫曼本人也承认） |
| **定性模糊** | Lollapalooza效应等核心概念缺乏严格量化定义，易被事后归因 |
| **幸存者偏差** | 伯克希尔长期成功被过度归因于模型，少讨论运气和时代背景 |
| **精英主义** | 体系依赖长期复利和大额初始资本，对普通投资者参考性打折扣 |
| **模型滥用** | 后人整理的"100模型清单"导致贴标签式浅层拼凑，偏离芒格网状思考本意 |

## 与其他思想家的边界混淆

常见混淆需要澄清：

| 误区 | 澄清 |
|------|------|
| 将巴菲特观点误归芒格 | 巴菲特是执行者，芒格是架构师；芒格更强调跨学科、逆向、避错 |
| 将格雷厄姆观点混淆 | 格雷厄姆：买便宜；芒格推动：以合理价格买伟大企业 |
| 将雅可比逆向思考全归芒格 | 芒格是推广应用者，不是原创者 |
| 将"100个思维模型"归芒格 | 芒格从未给出清单，只说约80-90个模型；清单是后人整理 |
